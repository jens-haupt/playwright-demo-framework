# Playwright Demo Framework

Modern Playwright test automation framework showcasing scalable QA automation practices, CI/CD integration and maintainable test architecture.

---

## Tech Stack

- Playwright
- TypeScript
- GitHub Actions
- CI/CD
- Page Object Model
- HTML Reporting

---

## Features

- End-to-End UI Testing
- Cross-browser support
- Automated CI pipeline
- Maintainable test structure
- HTML test reports

---

## Demo Application

https://www.saucedemo.com

---

## Run Tests

```bash
npx playwright test
```

---

## Open HTML Report

```bash
npx playwright show-report
```
